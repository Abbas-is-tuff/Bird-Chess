# 🐦 Bird Chess 3D

A chess.com-style chess game where every piece is one of my pet birds, in full 3D.

**Play:** open `index.html` (or the GitHub Pages link) in any browser.

## The flock
| Piece | Bird |
|---|---|
| ♔ White King | Mini Snowflake |
| ♚ Black King | Salman (African grey) |
| ♕ Queens | Jafar (zebra finch) |
| ♖ Rooks | Abbas (lovebird) |
| ♗ Bishops | Ananas |
| ♘ Knights | Lemon & Coco (rainbow lorikeets) |
| ♙ Pawns | Snowflake |

## Features
- Realistic 3D board — birds fly across the board when they move (2D view too)
- 16 bird bots from Mercury (250) to **Salman (3000, powered by Stockfish)**
- Home screen with Quick Match, Flock Ladder tournament, Coach with hints, puzzles, Learn, Watch bot-vs-bot
- Ratings, stats and streaks saved on your device
- Clocks, move list, eval bar, takebacks, draws, sounds
- Online multiplayer with game codes (works in the Claude version of the game)
- Installable / works offline (`sw.js`)
